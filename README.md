# Rool JavaScript

Official TypeScript SDK and Svelte bindings for [Rool](https://rool.dev).

## Packages

| Package            | Description                      |
| ------------------ | -------------------------------- |
| `@rool-dev/sdk`    | TypeScript SDK for Rool Machines |
| `@rool-dev/svelte` | Svelte 5 bindings for the SDK    |

## Development

```bash
pnpm install
pnpm build
pnpm typecheck
```
